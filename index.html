Checking where this can be saved…

Where it lives. Everything you enter stays in this browser's storage on this device. There is no account and no server holding your figures. Clearing site data, or deleting the app, deletes them — so take a backup.

What leaves the device. Only watched addresses. They're looked up on mempool.space, which means that server sees which addresses you asked about. Prices come from CoinGecko. Typed amounts are never sent anywhere.

Monero can't be watched by address. Stealth addresses mean an XMR address reveals nothing publicly — reading a balance needs your private view key, which this app will never ask for. Enter Monero amounts by hand.

Never enter a seed phrase or private key here. This app can only read public data. It cannot sign or send anything.
